# 把妹大师 V24.0 - Viking 大模型版

## 🎯 核心特性

**V24.0 = V11 的 API 调用 + V23 的 Viking 上下文管理**

- ✅ **MiniMax 大模型 API** - 真正的高情商回复生成
- ✅ **Viking 上下文管理** - 记忆/技巧/场景三维检索
- ✅ **智能 Prompt 工程** - 整合上下文生成个性化回复
- ✅ **多女生管理** - 每个女生独立记忆
- ✅ **兴趣度分析** - 分析她对你的感觉

## 🚀 快速开始

### 1. 配置 API Key

**方式 1: 运行配置工具**
```bash
python3 setup_v24.py
```

**方式 2: 创建配置文件**
```bash
# 创建 config.json
cat > config.json << 'EOF'
{
  "api_key": "sk-cp-你的 API Key",
  "model": "MiniMax-M2.7"
}
EOF
```

**方式 3: 命令行配置**
```bash
python3 main_cli_v24.py
# 选择选项 5 配置 API Key
```

### 2. 启动程序

**命令行版 (推荐)**
```bash
python3 main_cli_v24.py
```

**智能启动 (自动检测)**
```bash
python3 start_smart.py
```

## 🎯 核心功能

### 1. 大模型回复生成
- 基于 MiniMax-M2.7 模型
- 根据上下文生成个性化回复
- 每次生成 3 条选项

### 2. Viking 上下文管理
- **记忆管理** - 记住每个女生的喜好和互动
- **对话历史** - 保留最近对话，自动压缩
- **长期记忆** - 重要对话永久保存

### 3. Prompt 工程
```python
【当前关系】恋人
语气指导：甜蜜亲密，体现关心和爱意

【对方名字】小美

【历史记忆】
- 她说喜欢喝咖啡，特别是拿铁
- 她养了一只猫，叫奶茶

【最近对话】
TA: 在干嘛呢
我：在呢在呢，想你啦~

【TA 刚说】
今天好累啊

请生成 3 条高情商回复，每行一条：
```

### 4. 兴趣度分析
- 分析聊天记录中的情绪信号
- 0-100 分评分
- 给出下一步建议

## 💡 使用技巧

1. **首次使用先配置 API Key**
   - 访问 https://platform.minimaxi.com/
   - 注册账号并创建 API Key

2. **多女生管理**
   - 每次聊天前选择女生名字
   - 每个女生独立记忆
   - 可以随时切换

3. **记忆积累**
   - 自动记忆每次对话
   - 记忆越多，回复越精准
   - 可以手动查看/清空记忆

4. **关系类型**
   - 根据实际关系选择
   - 不同关系不同语气
   - 支持 8 种关系类型
