# 微信高情商回复助手 V9.0

一款基于 AI 的微信高情商回复辅助工具，支持智能生成回复、好友画像分析、聊天记录分析等功能。

## ✨ V9.0 新特性

### 🎯 核心优化
- **意图识别准确率 100%** - 16 种意图精确识别（checkin/question/meal/invite/affection 等）
- **连续对话不混乱** - 每条消息根据意图返回对应回复，不再语无伦次
- **好友画像分析** - AI 分析好友性格特点、聊天风格、重要事件
- **高情商回复工作流** - 画像 + 记忆 + 上下文 + 关系 + 时间情境

### ⚡ 性能优化
- **缓存系统** - 回复缓存（30 分钟 TTL）+ 画像缓存（24 小时 TTL）
- **请求限流** - 10 次/秒，避免 API 超限
- **批量测试** - 支持并发测试评估

## 🚀 快速开始

### 环境要求
- Python 3.8+
- Windows 操作系统（支持 macOS/Linux）
- MiniMax API Key（可选，用于 AI 回复）

### 安装依赖
```bash
pip install requests pillow
```

### 启动程序
```bash
# Windows
双击 启动 V8.bat

# 命令行
python main_v8.py
```

### 配置 API Key
1. 点击界面上的「⚙️ 设置」
2. 输入 MiniMax API Key
3. 保存即可

> 无 API Key 时使用本地模板模式，也能生成回复

## 🧠 核心功能

### 1. 好友画像分析
根据聊天记录分析：
- 基础信息（称呼/关系/互动频率）
- 聊天风格（表达长度/语气/表情使用）
- 性格特点（外向程度/情绪表达/决策风格）
- 重要事件（生日/工作变动/情感状态）
- 关系亲密度评估

### 2. 高情商回复生成
输入信息：
- 好友画像
- 关系类型（8 种）
- 最近聊天记忆
- 当前消息
- 时间情境

输出：
- 3 条回复选项（8-20 字）
- 符合微信聊天习惯
- 语意清晰不重复

### 3. 关系类型支持
| 关系 | 语气指导 |
|------|----------|
| 恋人 | 甜蜜亲密，体现关心和爱意 |
| 朋友 | 自然轻松，幽默风趣 |
| 同事 | 专业礼貌，保持适当距离 |
| 客户 | 商务专业，稳妥可靠 |
| 家人 | 亲情温暖，体贴关怀 |
| 追求者 | 委婉得体，不伤害对方 |
| 海王 | 保持暧昧，欲拒还迎 |
| 高冷 | 简洁冷淡，爱搭不理 |

### 4. 回复风格
- **稳妥版** - 稳重得体，不会出错
- **轻松版** - 轻松俏皮，带点幽默
- **升温版** - 热情主动，拉近距离

### 5. 意图识别（16 种）
- checkin - 问候/在吗
- question - 询问/干嘛呢
- meal - 吃饭相关
- invite - 邀约
- affection - 表白/想念
- night - 晚安
- thanks - 感谢
- apology - 道歉
- care - 关心
- complaint - 抱怨
- share - 分享
- work - 工作
- help - 求助
- congratulate - 恭喜
- comfort - 安慰
- light - 敷衍回应
