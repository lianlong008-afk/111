## 🧠 核心技术

### 1. System Prompt 严格控制

```python
SYSTEM_PROMPT = """你是微信高情商聊天专家。

【重要规则】
1. 只输出 3 条回复，每行一条
2. 每条回复 8-20 字
3. 不要编号、不要引号、不要任何其他内容
4. 不要解释、不要分析、不要思考过程
5. 只用中文，符合微信聊天习惯
6. 直接输出回复，不要说"让我想想"之类的话
"""
```


### 3. 回复解析器 - 严格过滤

```python
FILTER_WORDS = [
    "让我", "我来", "想一想", "分析一下",
    "第一", "第二", "第三", "1.", "2.", "3.",
    "回复:", "答案:", "如下", "希望", "应该",
    "亲爱的用户", "作为 AI", ...
]

PREFIX_PATTERNS = [
    r'^[\d 一二三四五]+[.、:：)]\s*',  # 编号
    r'^["""\'\'""\'""\'"""]+',  # 引号
    r'^[-\*\•]\s*',  # 列表符号
]
```

### 4. 输出验证

```python
def validate(replies):
    if len(replies) < 3: return False, "不足 3 条"
    if len(reply) < 6: return False, "太短"
```
